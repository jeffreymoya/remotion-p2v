You are a video segment planner. Given a script, segment it into narrative beat groups that will become individual Remotion scenes.

## Script
{script}

## Instructions
Divide the script into segment groups following the question-ladder. Each group maps to one narrative beat:

| Group | Beat | Purpose |
|-------|------|---------|
| hook+promise | 1-2 | Cold hook + viewer promise |
| surface | 3-4 | Context + baseline explanation |
| mechanism | 5 | The underlying mechanism |
| evidence | 6 | Claim → evidence → implication |
| tradeoffs | 7-8 | Tradeoffs + practical framework |
| payoff+closing | 9-10 | Final judgment + closing loop |

For each group, extract:
- **label**: The group name (e.g. "hook+promise", "surface", etc.)
- **beat**: The narrative beat number and name (e.g. "1. Cold hook")
- **text**: The exact narration text for this segment (verbatim from the script)
- **durationSec**: Estimated duration in seconds for speaking this text (assume ~2.5 words per second natural speaking pace)

## Rules
- Every word from the script must belong to exactly one segment
- Duration must be realistic for spoken delivery
- Segments should be contiguous — no gaps between them

## Output
Return a JSON object with:
- **groups**: Array of { label, beat, text, durationSec }

Return ONLY valid JSON — no markdown, no explanatory text.
